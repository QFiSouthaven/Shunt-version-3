
# Aether Shunt OS (v3.0.0)

![Status](https://img.shields.io/badge/Status-Alpha-cyan) ![License](https://img.shields.io/badge/License-Proprietary-red) ![Stack](https://img.shields.io/badge/Stack-React_19_%7C_Vite_%7C_Tailwind-blue)
