
# Aether Shunt OS: User Operations Manual

This guide explains how to operate the core modules of the Aether Shunt Operating System.

---

## 1. Mission Control (The Dashboard)
The **Dashboard** is your landing page. It provides a high-level view of system health and acts as a launcher for all applications.
*   **Vitals:** Check the top bar for System Online status and Subscription Tier.
*   **Quick Launch:** Use the omnibar to type a quick task or navigate directly to a module.
*   **Command Palette:** Press `Ctrl+K` (or `Cmd+K`) anywhere in the app to open the global command menu.

---

## 2. Shunt (Text Transformation Engine)
Use Shunt for atomic text operations and prompt engineering.

### Workflow
1.  **Input:**
    *   Type or paste text into the central input area.
    *   Drag & Drop files to load them into context.
    *   Use the **Bulletin Board** (left panel) to attach persistent reference documents.
2.  **Control:**
    *   **Quick Actions:** Click buttons like "Summarize", "Amplify", or "Modernize Code".
    *   **Modular Engine:** Switch to the "Modular" tab to stack specific prompt behaviors (e.g., "Chain of Thought" + "Critic").
    *   **Smart Shunt:** Click the "Smart Shunt" button to let the AI analyze your input and automatically select the best tool.
3.  **Output:**
    *   View the result in the right panel.
    *   **Evolve:** Click the "Evolve" button to move the output back to the input field for further refinement.
    *   **Save:** Connect the MCP Extension to save results directly to your disk.

---

## 3. Weaver (Strategic Planner)
Use Weaver to generate comprehensive development plans and architecture documents.

### Workflow
1.  **Goal Setting:** Enter a high-level objective (e.g., "Build a React Native To-Do App").
2.  **Project Memory:** Use the left panel to update the "Gemini Context". This text serves as the long-term memory for the AI, informing all generated plans.
3.  **Generate:** Click "Generate Plan".
4.  **Review:** The AI will produce a structured JSON plan containing:
    *   Clarifying Questions
    *   Architectural Proposal
    *   Implementation Tasks (File paths and descriptions)
    *   Test Cases

---

## 4. Foundry (Multi-Agent Simulator)
Use Foundry to simulate a team of experts working on your project.

### Modes
*   **Forge (Agent Swarm):**
    *   Enter a goal.
    *   Watch as the "Cognitive Council" (Strategist, Architect, Engineer, etc.) audits, designs, and refines a solution.
    *   The system uses "Chain of Thought" to simulate internal monologues.
*   **Launch It:** Upload your project files to generate a "Launch Readiness Kit" (Deployment scripts, security audit).
*   **Merge (Seamless Integrator):** Upload two sets of files (Target and Source) to have the AI intelligently merge codebases using semantic understanding.

---

## 5. Tool for AI (Job Runner)
Use this module to execute complex, multi-step tasks that require a file system.

*   **Prompt:** Enter a command like "Refactor the auth folder to use async/await."
*   **Context:** Upload relevant files.
*   **Execution:** The AI "Agent" will spin up, read the files into its virtual file system, perform the edits, run virtual tests, and commit the changes to a virtual git branch.
*   **Result:** Download the modified files or view the execution logs.

---

## 6. Oraculum (Telemetry)
Monitor the cognitive load and performance of the OS.

*   **Live Feed:** Watch real-time events as you interact with other modules.
*   **Insights:** Click "Generate Insights" to have the AI analyze your session patterns and suggest optimizations.

---

## 7. Chronicle (Time Machine)
Access the history of every artifact generated by the system.

*   **Filter:** View by type (Plans, Code, Chat Logs).
*   **Diff:** Select a version to see exactly what changed compared to the previous iteration.
*   **Revert:** Restore older content to the active workspace.

---

## 8. Settings & Configuration
*   **Identity:** Sign in (Mock OAuth) to persist preferences.
*   **Local Intelligence:**
    *   **Provider:** Choose between LM Studio or Ollama.
    *   **Force Local:** Enable this to bypass the Cloud API entirely for privacy.
*   **Security:** Toggle "Input Sanitization" and "Prompt Injection Guard".
*   **MCP Extension:** Connect to the browser extension to enable real file system access.
